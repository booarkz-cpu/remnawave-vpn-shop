# Руководство администратора V43

## Первичная настройка

1. Создайте отдельного администратора.
2. Включите TOTP MFA.
3. Настройте Telegram ID только для админов без обязательного MFA Telegram-login сценария.
4. Проверьте домены и HTTPS.
5. Настройте Remnawave.
6. Настройте платежные провайдеры.
7. Пока E2E не пройден, production payments остаются заблокированы.

## Управление ботом

Admin → Content → Telegram Bot.

Можно менять название, кнопки, порядок, состояние, Web App/URL/field действия и картинку `/start`.

## Управление Mini App

Admin → Content → Mini App.

Можно менять заголовок, подзаголовок, инструкции, фон, основное изображение и быстрые действия.

## Безопасность

Критические операции должны выполняться только администратором с нужным permission. После смены пароля, роли, Telegram ID или отключения аккаунта существующие сессии отзываются.

## Платежи

Перед production:

`Diagnostics → Staging E2E → полный внешний sandbox E2E → Security → Production Gate`.

Не нажимайте обходные/ручные способы изменения gate.
