# Remnawave VPN Shop 2.2.1 — руководство

## Что нового

Релиз объединяет коммерческие возможности, эксплуатацию и безопасность в одном контуре.

### Клиент
- уведомления внутри личного кабинета;
- управление устройствами;
- подписки, продление и отмена;
- подарочные коды;
- промокоды с ограничениями;
- реферальная программа;
- поддержка через тикеты.

### Администратор
- клиентская карточка 360;
- финансовый журнал;
- антифрод;
- мониторинг;
- инциденты;
- резервные копии и восстановление;
- feature flags;
- управление провайдерами;
- статусная страница;
- контролируемые canary/blue-green/rolling-развёртывания.

### API
- `GET /api/me/notifications` — уведомления клиента;
- `POST /api/me/notifications/{id}/read` — отметить прочитанным;
- `GET /api/public/status` — публичное состояние сервиса;
- `/api/admin/notifications` — очередь уведомлений;
- `/api/admin/status/components` — компоненты статусной страницы;
- `/api/admin/deployments` — журнал и управление развёртываниями.

## Важное ограничение

Контроллер развёртываний не притворяется оркестратором: изменение процента трафика фиксируется как управляемое состояние, а фактическое переключение трафика выполняет инфраструктурный deployment pipeline. Это исключает ложное ощущение автоматического rollback без интеграции с вашим оркестратором.

## Обновление

1. Сделайте резервную копию.
2. Выполните `alembic upgrade head`.
3. Запустите backend и worker.
4. Проверьте `/health/ready`.
5. Проверьте `/api/public/status`.
6. Только после успешной проверки включайте реальные платежи.
