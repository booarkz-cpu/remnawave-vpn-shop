# v4 release

Implemented:
- SSH VPS provisioning for Remnawave Node.
- Uses the exact Node compose generated by the Remnawave Panel.
- Automatic Docker installation.
- `/opt/remnanode` deployment.
- `docker compose pull/up`.
- Optional UFW rule restricting NODE_PORT to Panel IP.
- Admin Bearer-token protection for `/api/admin/*`.
- Admin UI wizard for Node deployment.
- SSH secrets are not stored in the DB.
- Security documentation.

The official Remnawave docs describe this Node workflow and explicitly recommend
restricting NODE_PORT to the Panel IP.
